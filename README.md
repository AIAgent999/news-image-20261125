# The World Today — Wednesday, 25 November 2026

A one-image newspaper front page summing up Wednesday 25 November 2026's world news. The hero story shows a night skyline of Riyadh as the Saudi capital's tallest tower is hit again in a Houthi strike that injured 11. Four panels below cover the day's other leads: Nvidia sliding 7% as an AI sell-off rattled world markets (Nikkei -2.8%, Seoul -5.8%); gunmen holding 25 hostages in a Cartagena, Colombia supermarket; tankers hitting mines in the Strait of Hormuz; and China investigating Politburo member Chen Jining. A footer notes the day's brighter story: the first foreign astronaut reaching China's space station. Running `main.py` copies the bundled `entry.png` to `/output/entry.png`, byte for byte.

Entry for the make.fun bounty [news-image-20261125](https://make.fun/bounty/news-image-20261125): a program that writes one image summing up the day's world news.
